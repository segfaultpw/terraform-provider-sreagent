# sreagent_secret_allow_rule (Resource)

A rule that keeps the weekly repository scan from filing a credential match, by path, repository and detector. A rule cannot be edited: any change replaces it (the old rule is deleted first, so for a moment the weekly scan could file a match it covered; set lifecycle create_before_destroy to avoid that, up to the 100 rule limit). Removing repository, detector_type or expires_at replaces the rule with one that covers every repository, every kind, or never ends, and the plan warns what widens. A rule whose end has passed cannot be edited: the plan fails, because the replacement would end in the past (set a later expires_at, or remove the block). A rule holds no credential and closes nothing already filed; mark those findings false positive in the app. An organization has at most 100 rules. Needs the infrastructure suite.

## Example Usage

```terraform
# Keep the weekly scan from filing credential matches in one repository's test fixtures,
# until the end of the year. A rule cannot be edited: any change replaces it.
resource "sreagent_secret_allow_rule" "fixtures" {
  path_glob  = "**/testdata/**"
  reason     = "Vendored test fixtures, not real keys"
  repository = "acme/web"
  expires_at = "2027-12-31T23:59:59Z"
}
```

## Schema

### Required

- `path_glob` (String) The paths the rule covers, at most 200 characters (** matches any run of characters including /, * any run without /, ? one character; case sensitive, from the repository root).
- `reason` (String) Why the match is not a credential, 10 to 500 characters. It must not quote the credential: the platform refuses a reason that looks like one.

### Optional

- `detector_type` (String) A detector type such as aws_access_key. Leave it out for every kind. The platform refuses a type it does not know, naming the ones it has.
- `expires_at` (String) When the rule ends, an RFC 3339 time with a zone in the future. Leave it out for never. The platform answers microseconds; the same instant written another way is no change.
- `repository` (String) owner/name, stored in lower case. Leave it out for every repository.

### Read-Only

- `created_at` (String) When the rule was added.
- `id` (String) The row's identifier on the platform.

# sreagent_ai_provider (Resource)

A model provider the organization brings. A provider inherited from a parent organization is not visible here.

## Example Usage

```terraform
variable "anthropic_api_key" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "sreagent_ai_provider" "anthropic" {
  name               = "anthropic"
  provider_type      = "anthropic"
  model              = "claude-sonnet-5"
  api_key_wo         = var.anthropic_api_key
  api_key_wo_version = 1
}

# Bedrock takes no API key: SRE Agent assumes an IAM role in your own AWS
# account. The role trusts the platform principal and your organization's
# ExternalId, so create it in the same apply and hand its ARN over. Narrow the
# policy's Resource to the models you enable.
data "sreagent_aws_external_id" "this" {}

resource "aws_iam_role" "bedrock" {
  name = "sre-agent-bedrock"
  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect    = "Allow"
      Action    = "sts:AssumeRole"
      Principal = { AWS = data.sreagent_aws_external_id.this.trust_principal_arn }
      Condition = { StringEquals = { "sts:ExternalId" = data.sreagent_aws_external_id.this.external_id } }
    }]
  })
}

resource "aws_iam_role_policy" "bedrock_invoke" {
  name = "invoke-models"
  role = aws_iam_role.bedrock.id
  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect   = "Allow"
      Action   = ["bedrock:InvokeModel", "bedrock:InvokeModelWithResponseStream", "bedrock:ListFoundationModels"]
      Resource = "*"
    }]
  })
}

resource "sreagent_ai_provider" "bedrock" {
  name          = "bedrock"
  provider_type = "bedrock"
  role_arn      = aws_iam_role.bedrock.arn
  region        = "us-east-1"
}
```

## Schema

### Required

- `name` (String) Unique within the organization.
- `provider_type` (String) The provider. One of: anthropic, openai, openrouter, ollama, bedrock, gemini, portkey, langchain.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `api_key_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The provider's API key. Not for bedrock, which has no key and is refused one: it takes role_arn and region; switching a provider to bedrock discards the key it held. Write-only: never stored in state or plan.
- `api_key_wo_version` (Number) Change this number to send api_key_wo again. Set it whenever api_key_wo is set.
- `auto_upgrade_model` (Boolean) Follow the provider's newest model.
- `base_url` (String) A custom endpoint.
- `enabled` (Boolean) Whether it is routed to.
- `max_tokens` (Number) Output token cap; unset means 4096.
- `model` (String) The default model.
- `model_overrides` (String) A model per purpose, as jsonencode({...}). "auto" hands a purpose to the platform's own model selection. A purpose removed from the map is cleared on the platform.
- `priority` (Number) Routing order.
- `rate_limit_rpm` (Number) Requests per minute.
- `region` (String) Bedrock only, and required for it: the region the models are called in, such as us-east-1 (lowercase, one of the regions the platform supports). Refused for every other provider.
- `role_arn` (String) Bedrock only, and required for it: the ARN of the IAM role in your own AWS account that SRE Agent assumes to call Bedrock. Its trust policy allows the principal and the ExternalId from data.sreagent_aws_external_id. Not a secret. Refused for every other provider.
- `temperature` (Number) Sampling temperature; a new provider starts at 0.7.
- `timeout_ms` (Number) Request timeout; a new provider starts at 60000.

### Read-Only

- `api_key_set` (Boolean) Whether the platform holds a value for api_key.
- `id` (String) The row's identifier on the platform.

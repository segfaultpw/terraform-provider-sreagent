# sreagent_security_sla_policy (Resource)

The days a security finding may stay active before it breaches, per severity. The platform's defaults are 7 days for critical, 30 for high, 90 for medium, 180 for low and no SLA for info; a severity with no days has no SLA. As a resource it adopts the settings the organization has: an attribute left out is left as it is, and destroying the resource leaves the settings in place (the platform has no row to delete). Needs the infrastructure suite. Changing a day recomputes the due date of every active finding of that severity. To go back to the defaults, state them (7, 30, 90, 180 and 0), apply, then remove the block.

## Example Usage

```terraform
# Days a finding may stay active before it breaches. A day left out is left as it is;
# 0 means no SLA for that severity.
resource "sreagent_security_sla_policy" "this" {
  critical_days = 3
  high_days     = 14
  medium_days   = 60
  low_days      = 180
  info_days     = 0
}
```

# sreagent_status_page_settings (Resource)

The public status page's settings. Branding fields need the custom branding plan feature. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
resource "sreagent_status_page_settings" "this" {
  enabled           = true
  title             = "Acme status"
  show_history_days = 30
}
```

# sreagent_image_target (Resource)

A container image scanned for CVEs. Needs the security plan feature. Rows cannot be edited, so a change replaces the target. An image a cluster or ECS discovery filed comes back on the next sweep after a destroy.

## Example Usage

```terraform
resource "sreagent_image_target" "api" {
  image_ref = "ghcr.io/acme/api:1.4.2"
}
```

# sreagent_connector (Resource)

An infrastructure connector runbooks act through.

## Example Usage

```terraform
variable "ssh_private_key" {
  type      = string
  sensitive = true
  ephemeral = true
}

# The whole config is stored encrypted, so it is write-only as a whole.
resource "sreagent_connector" "bastion" {
  name           = "bastion"
  connector_type = "ssh"
  config_wo = jsonencode({
    host        = "10.0.0.10"
    username    = "sre"
    private_key = var.ssh_private_key
  })
  config_wo_version = 1
}
```

### Required

- `name` (String) Unique within the organization.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `config_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The connector's settings and credentials, as jsonencode({...}). Required to create a connector. Stored encrypted as a whole, so it is write-only as a whole. Write-only: never stored in state or plan.
- `config_wo_version` (Number) Change this number to send config_wo again. Set it whenever config_wo is set.
- `enabled` (Boolean) Whether runbooks may use it.
- `metadata` (String) Free-form labels, as jsonencode({...}).

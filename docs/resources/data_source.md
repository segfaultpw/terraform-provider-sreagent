# sreagent_data_source (Resource)

A metrics, logs or cloud data source investigations query.

## Example Usage

```terraform
variable "prometheus_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "sreagent_data_source" "prometheus" {
  name      = "prometheus"
  type      = "prometheus"
  url       = "https://prometheus.example.com"
  auth_type = "bearer"
  auth_credentials_wo = jsonencode({
    token = var.prometheus_token
  })
  auth_credentials_wo_version = 1
}
```

## Schema

### Required

- `name` (String) Unique within the organization.
- `type` (String) prometheus, loki, cloudwatch and so on. Changing it replaces the source.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `auth_credentials_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The credentials for auth_type, as jsonencode({...}). For aws_assume_role send role_arn; the platform stamps the organization's ExternalId. Write-only: never stored in state or plan.
- `auth_credentials_wo_version` (Number) Change this number to send auth_credentials_wo again. Set it whenever auth_credentials_wo is set.
- `auth_type` (String) How the platform authenticates. Changing it to a type that takes credentials needs auth_credentials_wo with a new auth_credentials_wo_version in the same apply, because the stored credentials belong to the previous type. One of: none, basic, bearer, api_key, datadog_keys, aws_access_keys, aws_assume_role, aws_instance.
- `enabled` (Boolean) Whether investigations query it.
- `regions` (List of String) AWS regions this source covers.
- `url` (String) The endpoint; derived for AWS types.

### Read-Only

- `auth_credentials_set` (Boolean) Whether the platform holds a value for auth_credentials.
- `aws_account_id` (String) The AWS account the source reads.
- `id` (String) The row's identifier on the platform.
- `role_arn` (String) The role an aws_assume_role source assumes.

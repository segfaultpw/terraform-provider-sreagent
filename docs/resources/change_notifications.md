# sreagent_change_notifications (Resource)

Where deploy and config change announcements post in Slack. Needs a Slack workspace of this organization's own (sreagent_slack) first. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
# Needs the organization's own Slack workspace first.
resource "sreagent_change_notifications" "this" {
  enabled     = true
  channel     = "#deploys"
  event_types = ["deploy", "rollback"]
}
```

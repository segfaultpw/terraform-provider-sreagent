# sreagent_security_digest_settings (Resource)

The security digest: how often it is sent and where. It is off by default; switching it on needs a Slack channel or email. As a resource it adopts the settings the organization has: an attribute left out is left as it is, and destroying the resource leaves the settings in place (the platform has no row to delete). Needs the infrastructure suite. Destroying the resource does not switch the digest off: it keeps sending while enabled is true. To go back to the defaults, state them (enabled = false, cadence = "weekly", weekday = 1, hour = 9, slack_channel = "", email = false), apply, then remove the block.

## Example Usage

```terraform
# A weekly digest on Monday morning, to a Slack channel and by email.
resource "sreagent_security_digest_settings" "this" {
  enabled       = true
  cadence       = "weekly"
  weekday       = 1
  hour          = 8
  slack_channel = "#security"
  email         = true
}
```

## Schema

### Optional

- `cadence` (String) How often it is sent. One of: daily, weekly.
- `email` (Boolean) Whether the digest is emailed to the organization's notification list.
- `enabled` (Boolean) Whether the digest is sent. Needs a Slack channel or email.
- `hour` (Number) The hour, 0 to 23, in the organization's time zone.
- `slack_channel` (String) The Slack channel, such as #security, or an empty string for none (the platform stores no channel as null, which the data source reads as null). There is no default channel for a digest.
- `weekday` (Number) For a weekly digest, 1 (Monday) to 7 (Sunday).

### Read-Only

- `id` (String) The row's identifier on the platform.
- `last_sent_at` (String) When the last digest was sent.
- `last_sent_period` (String) The period the last digest covered.
- `timezone` (String) The time zone the hour is read in.

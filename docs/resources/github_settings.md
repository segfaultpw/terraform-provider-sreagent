# sreagent_github_settings (Resource)

The GitHub App installation's settings. Needs a connected installation. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
# Needs a connected GitHub App installation.
resource "sreagent_github_settings" "this" {
  draft_prs             = true
  review_enabled        = true
  review_severity_floor = "high"

  # Auto-merge only what SRE Agent verified: a fix whose checks did not run for
  # it never merges by itself, even where a repository's auto_merge is on.
  auto_merge_requires_verification = true
}
```

## Schema

### Optional

- `auto_merge_requires_verification` (Boolean) Auto-merge only what SRE Agent verified. Off by default: a fix SRE Agent's own checks did not run for can still merge by itself once the checks its branch requires pass (where a repository's auto_merge says so), and a change pushed onto a pull request afterwards merges on those checks alone. An organization admin takes that risk by leaving it off. On: only a fix whose exact commit those checks ran on and passed merges by itself. In both positions a fix whose checks failed, or ran and could not judge it, or has an open self-review blocker, never merges by itself.
- `auto_pr_enabled` (Boolean) Open fix PRs automatically.
- `auto_revise_on_review` (Boolean) Revise a PR when a review asks.
- `context_repo` (String) A repository whose files give reviews context.
- `draft_prs` (Boolean) Open PRs as drafts.
- `link_comments_enabled` (Boolean) Comment links on linked issues.
- `review_enabled` (Boolean) Review pull requests.
- `review_severity_floor` (String) The lowest severity a review comments on. One of: critical, high, medium, low.

### Read-Only

- `account` (String) The installation's account.
- `connected` (Boolean) Whether an installation is connected.
- `id` (String) The row's identifier on the platform.
- `installation_id` (Number) The installation id.
- `stopped_from` (String) The id of the parent organization whose GitHub App this organization stopped using, null when it has not stopped.
- `stopped_note` (String) Why the installation reads as not connected after the organization stopped using its parent's GitHub App; null otherwise. A child organization changes this in the app (inheritance_stopped).

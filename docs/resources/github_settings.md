# sreagent_github_settings (Resource)

The GitHub App installation's settings. Needs a connected installation. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
# Needs a connected GitHub App installation.
resource "sreagent_github_settings" "this" {
  draft_prs             = true
  review_enabled        = true
  review_severity_floor = "high"
}
```

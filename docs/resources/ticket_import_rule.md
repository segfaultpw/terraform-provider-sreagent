# sreagent_ticket_import_rule (Resource)

What is imported from a ticket provider onto the board; one rule per provider. Destroying it stops imports; imported items stay.

## Example Usage

```terraform
resource "sreagent_ticket_import_rule" "jira" {
  provider_type = "jira"
  enabled       = true
  config = jsonencode({
    project = "OPS"
  })
}
```

# sreagent_overseer_settings (Resource)

The Overseer's schedule and budget. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
resource "sreagent_overseer_settings" "this" {
  enabled        = true
  cadence        = "daily"
  aggressivity   = "conservative"
  digest_enabled = true
}
```

## Schema

### Optional

- `aggressivity` (String) How much it proposes.
- `cadence` (String) How often it runs.
- `digest_enabled` (Boolean) Send a digest.
- `enabled` (Boolean) Run the Overseer.
- `max_tokens_per_run` (Number) Token budget per run.
- `max_tool_calls` (Number) Tool call budget per run.

### Read-Only

- `id` (String) The row's identifier on the platform.
- `last_skip_reason` (String) Why the last due run did nothing.
- `next_run_at` (String) When it runs next.

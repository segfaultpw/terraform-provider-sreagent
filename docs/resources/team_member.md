# sreagent_team_member (Resource)

One person on one team. The person must already be a member of the organization. Being on a team grants nothing; it decides who is told about the team's work.

## Example Usage

```terraform
resource "sreagent_team" "platform" {
  name = "platform"
}

# One resource per membership: Terraform never removes somebody added in the app.
resource "sreagent_team_member" "ana" {
  team_id = sreagent_team.platform.id
  email   = "ana@example.com"
}
```

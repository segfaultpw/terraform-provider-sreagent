# sreagent_security_code_classes (Resource)

The accepted other:<kind> code aliases counted as security findings, beyond the four built-in classes (hardcoded_secret, unsafe_deserialization, ci_unpinned_action and ci_plain_secret), which always count and are never listed. As a resource it adopts the settings the organization has: an attribute left out is left as it is, and destroying the resource leaves the settings in place (the platform has no row to delete). A block that is not imported overwrites what it names: the plan reads the current settings and warns what the apply will change, so import first to review it as a plan. Needs the infrastructure suite. classes is the complete list of marked classes: a class left out is unmarked, and [] unmarks them all. Unmarking a class closes its open security findings; marking it again restores them. Destroying the resource leaves the marks in place.

## Example Usage

```terraform
# The complete list of other:<kind> classes counted as security findings, in any order.
# Unmarking a class closes its open findings.
resource "sreagent_security_code_classes" "this" {
  classes = ["other:ssrf", "other:xxe"]
}
```

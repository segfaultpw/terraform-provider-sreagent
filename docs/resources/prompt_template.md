# sreagent_prompt_template (Resource)

A prompt the AI uses. Making one the default clears is_default on the others of its type, which shows as drift on those.

## Example Usage

```terraform
resource "sreagent_prompt_template" "short_summary" {
  name        = "short summary"
  prompt_type = "custom"
  content     = "Summarize the alert in two lines."
}
```

# sreagent_notification_settings (Resource)

Email notification settings. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
resource "sreagent_notification_settings" "this" {
  enabled    = true
  recipients = ["oncall@example.com"]
  notify_slo = true
}
```

## Schema

### Optional

- `enabled` (Boolean) Send notification emails.
- `muted_events` (List of String) Event types never emailed.
- `notify_automation` (Boolean) Email on automation events.
- `notify_incidents` (Boolean) Email on incidents.
- `notify_security` (Boolean) Email on security events.
- `notify_slo` (Boolean) Email on SLO events.
- `recipients` (List of String) Who receives them.

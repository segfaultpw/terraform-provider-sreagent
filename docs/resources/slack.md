# sreagent_slack (Resource)

The organization's Slack workspace. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
variable "slack_bot_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

variable "slack_signing_secret" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "sreagent_slack" "this" {
  name                      = "acme"
  default_channel_critical  = "#pager"
  bot_token_wo              = var.slack_bot_token
  bot_token_wo_version      = 1
  signing_secret_wo         = var.slack_signing_secret
  signing_secret_wo_version = 1
}
```

- `signing_secret_wo_version` (Number) Change this number to send signing_secret_wo again. Set it whenever signing_secret_wo is set.
- `team_id` (String) The T... workspace id, verified against Slack with the bot token.

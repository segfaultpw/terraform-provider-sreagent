# sreagent_outbound_config (Resource)

An escalation target: PagerDuty, Grafana, a webhook, Slack or an on-call schedule.

## Example Usage

```terraform
variable "pagerduty_routing_key" {
  type      = string
  sensitive = true
  ephemeral = true
}

# The routing key is write-only: it is sent when routing_key_wo_version
# changes and is never stored in state. Bump the version to rotate it.
resource "sreagent_outbound_config" "pagerduty" {
  name                   = "pagerduty"
  provider_type          = "pagerduty"
  routing_key_wo         = var.pagerduty_routing_key
  routing_key_wo_version = 1
}
```

## Schema

### Required

- `name` (String) Unique within the organization.
- `provider_type` (String) Which system this target reaches. One of: pagerduty, grafana, webhook, slack, oncall_schedule.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `api_key_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The bearer token for a webhook or Grafana target. Write-only: never stored in state or plan.
- `api_key_wo_version` (Number) Change this number to send api_key_wo again. Set it whenever api_key_wo is set.
- `base_url` (String) The endpoint for a webhook or Grafana target.
- `default_severity_mapping` (String) Platform severity to provider severity, as jsonencode({...}). Unset uses the built-in mapping.
- `enabled` (Boolean) Whether the target receives pages.
- `oncall_schedule_id` (String) The schedule for an on-call target.
- `priority` (Number) Order among targets.
- `routing_key_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The PagerDuty integration routing key. Write-only: never stored in state or plan.
- `routing_key_wo_version` (Number) Change this number to send routing_key_wo again. Set it whenever routing_key_wo is set.
- `slack_channel` (String) The channel for a Slack target.

### Read-Only

- `api_key_set` (Boolean) Whether the platform holds a value for api_key.
- `id` (String) The row's identifier on the platform.
- `routing_key_set` (Boolean) Whether the platform holds a value for routing_key.
- `rule_count` (Number) Escalation rules pointing at this target.

# sreagent_security_notification_rule (Resource)

A rule that decides which security findings notify whom: its areas, the lowest severity, the events, and where it goes (Slack, email, paging). An attribute left out takes the platform's default (on, every area, minimum severity high, the new_finding event, Slack and email on, paging off), so removing page = true stops paging. An organization has at most 20 rules, each name unique; the platform refuses the 21st at apply. The organization's first rule, Critical and high findings, is created once by the platform: import it to manage it (its events are new_finding, sla_breached, acceptance_expired and fix_verified, so a block that leaves events out plans a change to new_finding). Destroying a rule deletes it; destroying every rule, the seeded one included, is permanent: the platform never creates it again, and an organization with no rule is sent no security notice. Needs the infrastructure suite.

## Example Usage

```terraform
# Page on call for every new critical finding, and post it to a channel.
resource "sreagent_security_notification_rule" "critical" {
  name          = "Critical findings"
  min_severity  = "critical"
  events        = ["new_finding", "sla_breached"]
  slack_channel = "#security-alerts"
  email         = false
  page          = true
}
```

## Schema

### Required

- `name` (String) The rule's name, 1 to 80 characters, unique in the organization.

### Optional

- `areas` (List of String) The areas the rule covers; empty means every area (the default). One of: secrets, iam, kubernetes, images, dependencies, anomalies, drift, code, certificates.
- `email` (Boolean) Whether the rule emails. Defaults to true.
- `enabled` (Boolean) Whether the rule is on. Defaults to true.
- `events` (List of String) The events that notify, at least one. Defaults to new_finding. One of: new_finding, sla_breached, acceptance_expiring, acceptance_expired, fix_verified.
- `min_severity` (String) The lowest severity that matches. Defaults to high. One of: info, low, medium, high, critical.
- `page` (Boolean) Whether the rule pages on call. Only a rule whose min_severity is critical may page, and only new findings page. Defaults to false.
- `slack` (Boolean) Whether the rule posts to Slack. Defaults to true.
- `slack_channel` (String) The Slack channel, such as #security-alerts. Leave it out for the organization's default channels.

### Read-Only

- `id` (String) The row's identifier on the platform.
- `updated_at` (String) When the rule last changed.

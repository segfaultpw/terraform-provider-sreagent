# sreagent_lead_agent_settings (Data Source)

What SRE Agent does when it is given work, as Settings, SRE Agent on cards shows it: for each place work comes from (a card, a Slack thread, an alert) whether it does nothing (off), plans and waits for a member to accept or run a step (suggest) or acts (act), whether a plan needs a member's acceptance, how much one goal may spend (wakes, tokens and hours), and for alerts whether it may page, act without a person, the lowest severity it takes and how many alerts it starts an hour. Read only: an organization admin changes it in Settings (or with the MCP tool update_lead_agent_settings), and the platform publishes no Terraform type for it. A place that has not been switched on is off or suggest by default, and defaults says whether these are the platform's. Needs platform v0.524.0.

## Example Usage

```terraform
# Read only: an organization admin changes what SRE Agent does with work it is
# given in Settings, SRE Agent on cards.
data "sreagent_lead_agent_settings" "this" {}

output "lead_agent_modes" {
  value = {
    card  = data.sreagent_lead_agent_settings.this.card_mode
    slack = data.sreagent_lead_agent_settings.this.slack_mode
    alert = data.sreagent_lead_agent_settings.this.alert_mode
  }
}
```

## Schema

### Read-Only

- `alert_act_unattended` (Boolean) Whether SRE Agent may request a fix or run a runbook for an alert without a person, within what self-healing allows.
- `alert_min_severity` (String) The lowest severity of alert it takes: critical, high or medium.
- `alert_mode` (String) What it does with a new alert: off, suggest (it plans in the background and the automatic investigation runs as before) or act.
- `alert_paging` (Boolean) Whether SRE Agent may page the person on call for a critical or high alert that still fires.
- `alert_starts_per_hour` (Number) How many alerts it starts on in an hour, 1 to 10.
- `bounds` (String) The limits each of max_wakes, max_tokens and max_hours may be set within.
- `card_mode` (String) What SRE Agent does with a card given to it: off, suggest or act.
- `configured` (Boolean) Always true: every organization has this resource. A platform that does not serve it fails the read with an error instead.
- `defaults` (Boolean) True while the organization has not saved a choice and the platform's defaults apply.
- `id` (String) The row's identifier on the platform.
- `max_hours` (Number) How long one goal may stay open, in hours.
- `max_tokens` (Number) The most model tokens one goal may count.
- `max_wakes` (Number) The most steps one goal may take.
- `modes` (String) The modes a place may be set to.
- `plan_approval` (Boolean) Whether a plan needs a member's acceptance before anything is delegated.
- `slack_mode` (String) What it does with a request made in a Slack thread: off, suggest or act.
- `updated_at` (String) When the settings last changed, or null while they hold the defaults.

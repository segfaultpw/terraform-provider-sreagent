# sreagent_ticket_schedules (Data Source)

Every ticket_schedule row, read-only. The recurring cards of the organization's board: each opens a card from a template on a daily, weekly or monthly rhythm, assigned to a person or to whoever is on call, with an optional due date. Read only: an organization admin writes a schedule on the board's Templates page or over MCP, and the platform publishes no Terraform type for it. Needs platform v0.523.0.

## Example Usage

```terraform
# Read only: an organization admin writes recurring cards on the board's Templates page.
data "sreagent_ticket_schedules" "all" {}

output "next_runs" {
  value = { for s in data.sreagent_ticket_schedules.all.items : s.name => s.next_run_at }
}
```

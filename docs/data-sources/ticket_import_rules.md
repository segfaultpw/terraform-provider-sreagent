# sreagent_ticket_import_rules (Data Source)

Every ticket_import_rule row, read-only. What is imported from a ticket provider onto the board; one rule per provider. Destroying it stops imports; imported items stay.

## Example Usage

```terraform
data "sreagent_ticket_import_rules" "all" {}

output "ticket_import_rules_count" {
  value = length(data.sreagent_ticket_import_rules.all.items)
}
```

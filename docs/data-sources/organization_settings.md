# sreagent_organization_settings (Data Source)

The organization's own settings. One row per organization: creating it adopts the current settings, destroying it leaves them in place.

## Example Usage

```terraform
data "sreagent_organization_settings" "this" {}

# Who may ask SRE Agent for a fix pull request (org_admin or member). An org
# admin changes it in the app; Terraform only reads it.
output "fix_request_floor" {
  value = data.sreagent_organization_settings.this.fix_request_floor
}

# How reactions travel between a card and its Slack threads (both, from_slack or off).
output "slack_reaction_sync" {
  value = data.sreagent_organization_settings.this.slack_reaction_sync
}
```

## Schema

### Read-Only

- `ai_budget_warn_percent` (Number) Warn at this share of the budget.
- `alert_grouping_ai_enabled` (Boolean) Group related alerts with AI.
- `alert_refire_cooldown_minutes` (Number) 0 to 1440.
- `alert_storm_threshold` (Number) Alerts within the window that make a storm.
- `alert_storm_window_seconds` (Number) The storm window.
- `api_key_max_days` (Number) The longest life, in days, a new API key or personal token may be given, or null for no limit. Changed by an org admin in the app.
- `auto_close_incidents` (Boolean) Close incidents automatically.
- `auto_open_incidents` (Boolean) Open incidents automatically.
- `automation_approval_ttl_minutes` (Number) How long an approval stays valid.
- `board_column_emoji` (Map of String) The emoji shown before each board column's name, as the whole set: a map from a column (backlog, triage, todo, in_progress, blocked or done) to one emoji written as the emoji itself. A column left out has no emoji, so {} removes them all; the map replaces what the organization holds, so a column the platform has an emoji for and the configuration leaves out is removed. Display only: it changes what the board's column headers, the Move to menu, the card's status buttons and the new card form say. The platform stores the fully qualified form of each emoji; a value written without a selector (for example a heart spelled as one code point) is accepted, kept as you wrote it in state and plans no change. A Slack name such as :white_check_mark: is accepted by the platform but stores the emoji it names, so it is refused here instead of planning a change on every run, and so is a column with a null value (leave it out). An organization admin's key (api:admin) may change it.
- `board_tile_reactions` (Boolean) Whether board tiles show a card's three most used reactions with their counts. On by default; each person can choose otherwise on their account page, and their choice wins. An organization admin's key (api:admin) may change it.
- `configured` (Boolean) False when the organization has no row of its own yet (or reads its parent's); every other attribute is then null.
- `fix_request_floor` (String) Who may ask SRE Agent for a fix pull request, or to change one it opened: org_admin for org admins only, member for members too. Changed by an org admin in the app.
- `id` (String) The row's identifier on the platform.
- `incident_severity_floor` (String) The lowest severity that opens an incident.
- `inheritance_stopped` (List of String) The connections of the parent organization this organization does not use, as the whole set: slack, github_installation, ai_providers, outbound_targets, ticket_integrations. Only a child organization can stop using a parent's. The platform refuses a change of the list from an API key, so a value that differs from the one it holds fails the apply; set it in the app. The platform also keeps a sixth kind, repository_defaults, which this list never reads, sends or accepts: it is changed in the app, and sreagent_repository_defaults gives a child its own defaults instead.
- `investigation_cooldown_minutes` (Number) Minutes between investigations of one alert.
- `investigation_paused` (Boolean) Pause automatic investigations.
- `language` (String) The language of the outcome lines SRE Agent writes into a card's Slack threads: how a fix, a change or a pull request ended, a card moved to Done or closed as won't do, and the label in front of a comment posted from the card. en (English, the default) or es (Spanish). Names, links, error messages and what people and the AI wrote are posted as they are. The card itself, its comments, the app's pages and emails stay in English. An organization admin's key (api:admin) may change it.
- `looking_window_hours` (Number) How many hours the board shows who is looking at a card after they put eyes on it: 4, 8, 24 (the default) or 72, or null to show them until they remove the reaction. An organization admin's key (api:admin) may change it.
- `mfa_effective` (String) The two-step rule that applies to this organization, counting the strictest of its own and its parent's settings.
- `mfa_grace_days` (Number) Days a person has to enrol a second step once it is required, 0 to 30. Changed by an org admin in the app.
- `mfa_required` (Boolean) Whether the organization requires two-step sign-in. Changed by an org admin in the app.
- `monthly_ai_budget_usd` (Number) The monthly AI budget.
- `reaction_meanings_off` (List of String) The reaction meanings switched off, as the whole set: [] leaves every meaning on (the default). looking is eyes on a card making the person a watcher and showing their face on its tile; take_it is a raised hand on a card nobody is assigned to assigning it to the person; tell_author is telling people, in the attention list and the morning briefing, when others react to their cards and comments; answer_feedback is recording a thumbs up or down on an assistant answer or an investigation as feedback on it. The order does not matter. A reaction already made keeps its chip. The data source lists every meaning the platform holds, including one a later platform release adds that the resource does not manage. An organization admin's key (api:admin) may change it.
- `reaction_quick_row` (List of String) The emoji shown first when someone adds a reaction, in order, as the whole list: up to 12, each one emoji (the platform refuses an entry over 16 code points or 64 bytes) written as the emoji itself, never repeated (the same emoji spelled with and without its presentation selector counts as a repeat). [] uses SRE Agent's twelve. The platform stores the fully qualified form of each emoji; an entry written without a selector (for example a heart or a thumbs up spelled as one code point) is accepted, kept as you wrote it in state and plans no change. A Slack name such as :tada: is accepted by the platform but stores the emoji it names, so it is refused here instead of planning a change on every run. An organization admin's key (api:admin) may change it.
- `restrict_domain_signups` (Boolean) Only allow sign-ups from the organization's domains. Changed by an admin in the app.
- `session_idle_effective` (Number) The idle sign-out limit that applies to this organization, in minutes, counting its parent's, or null for none.
- `session_idle_minutes` (Number) Minutes of inactivity after which a browser session is signed out, 5 to 43200, or null for no limit. Changed by an org admin in the app.
- `slack_reaction_counts` (Boolean) Whether SRE Agent's messages in a card's Slack thread carry the board's counts ("On the board: :+1: 2"). On by default. An organization admin's key (api:admin) may change it.
- `slack_reaction_sync` (String) How reactions travel between a card and its Slack threads: both (the default), from_slack (a reaction in Slack shows on the card, and SRE Agent adds none in Slack) or off (nothing arrives from Slack, and SRE Agent adds none). Switching never removes reactions already in place. An organization admin's key (api:admin) may change it.
- `slack_thread_events_off` (List of String) The events NOT posted in a card's Slack threads, as the whole set: [] posts everything (the default), and a list posts everything else. The order does not matter. Failed, declined or cancelled fixes and changes, a failed local fix session, a change that could not be made on the pull request it was asked for and the assistant's answer to a question asked in Slack are always posted and have no name here. The card, the tracker and the notices to the card's people are not affected.
- `social_joins_enabled` (Boolean) Allow joining through social sign-in. Changed by an admin in the app.
- `timezone` (String) An IANA time zone.

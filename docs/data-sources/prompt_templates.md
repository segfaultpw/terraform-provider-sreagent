# sreagent_prompt_templates (Data Source)

Every prompt_template row, read-only. A prompt the AI uses. Making one the default clears is_default on the others of its type, which shows as drift on those.

## Example Usage

```terraform
data "sreagent_prompt_templates" "all" {}

# A capped list says when it may hold more rows than it answered.
output "prompt_templates_truncated" {
  value = data.sreagent_prompt_templates.all.truncated
}
```

# sreagent_security_digest_settings (Data Source)

The security digest: how often it is sent and where. This data source only reads; sreagent_security_digest_settings manages it.

## Example Usage

```terraform
data "sreagent_security_digest_settings" "this" {}

output "security_digest_goes_to" {
  value = data.sreagent_security_digest_settings.this.slack_channel
}
```

## Schema

### Read-Only

- `cadence` (String) daily or weekly.
- `configured` (Boolean) Always true when the read succeeds; the read never answers false with null attributes. It fails with an error instead when the platform predates the resource, and when the organization's plan does not include the infrastructure suite (the platform answers 403).
- `email` (Boolean) Whether the digest is emailed.
- `enabled` (Boolean) Whether the digest is sent.
- `hour` (Number) The hour, 0 to 23, in the organization's time zone.
- `id` (String) The row's identifier on the platform.
- `last_sent_at` (String) When the last digest was sent.
- `last_sent_period` (String) The period the last digest covered.
- `slack_channel` (String) The Slack channel, such as #security, or null for none.
- `timezone` (String) The time zone the hour is read in.
- `weekday` (Number) For a weekly digest, 1 (Monday) to 7 (Sunday).

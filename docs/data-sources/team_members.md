# sreagent_team_members (Data Source)

Every team_member row, read-only. One person on one team. The person must already be a member of the organization. Being on a team grants nothing; it decides who is told about the team's work.

output "team_members_count" {
  value = length(data.sreagent_team_members.all.items)
}

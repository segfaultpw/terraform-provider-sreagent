# sreagent_ticket_templates (Data Source)

Every ticket_template row, read-only. The card templates of the organization's board: a saved starting point for a card (its title, description, labels, priority, team, service and checklist) that a member picks when making a card, that a card is saved as, and that a recurring card (data.sreagent_ticket_schedules) is made from. Read only: a member writes a template on the board's Templates page or over MCP, and the platform publishes no Terraform type for it. Needs platform v0.523.0.

## Example Usage

```terraform
# Read only: a member writes card templates on the board's Templates page.
data "sreagent_ticket_templates" "all" {}

output "template_names" {
  value = [for t in data.sreagent_ticket_templates.all.items : t.name]
}
```

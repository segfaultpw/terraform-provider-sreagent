# sreagent_certificate_monitors (Data Source)

Every certificate_monitor row, read-only. Watches a TLS certificate's expiry. Needs the security plan feature. Rows cannot be edited, so any change replaces the monitor.

## Example Usage

```terraform
data "sreagent_certificate_monitors" "all" {}

output "certificate_monitors_count" {
  value = length(data.sreagent_certificate_monitors.all.items)
}
```

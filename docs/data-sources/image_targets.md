# sreagent_image_targets (Data Source)

Every image_target row, read-only. A container image scanned for CVEs. Needs the security plan feature. Rows cannot be edited, so a change replaces the target. An image a cluster or ECS discovery filed comes back on the next sweep after a destroy.

## Example Usage

```terraform
data "sreagent_image_targets" "all" {}

output "image_targets_count" {
  value = length(data.sreagent_image_targets.all.items)
}
```

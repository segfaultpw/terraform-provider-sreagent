# sreagent_synthetic_checks (Data Source)

Every synthetic_check row, read-only. An HTTP, TCP or DNS probe run from the platform's regions. Needs the synthetic checks plan feature.

## Example Usage

```terraform
data "sreagent_synthetic_checks" "all" {}

output "synthetic_checks_count" {
  value = length(data.sreagent_synthetic_checks.all.items)
}
```

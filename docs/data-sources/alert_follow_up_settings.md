# sreagent_alert_follow_up_settings (Data Source)

The alert follow-up setting, as the Settings card shows it: whether SRE Agent checks alerts that stay open, what it does with one its source says has cleared, the ages at which it first checks, reminds, opens a card and escalates, the kinds of alert that are only being suggested for now, the informative kinds, and what the follow-up did in the last 7 days. Read only: an organization admin switches it on and changes it in Settings (or with the MCP tool update_alert_follow_up_settings), and it is off until then. Available on every plan.

## Example Usage

```terraform
# Read only: an organization admin switches the alert follow-up on, and changes
# it, in Settings. It is off until then.
data "sreagent_alert_follow_up_settings" "this" {}

output "alert_follow_up_enabled" {
  value = data.sreagent_alert_follow_up_settings.this.enabled
}

output "critical_alerts_cleared_by_their_source" {
  value = jsondecode(data.sreagent_alert_follow_up_settings.this.resolve_modes).critical
}

# The three switches an organization admin turns on in Settings, each off until then.
output "alert_follow_up_switches" {
  value = {
    telemetry_checks     = data.sreagent_alert_follow_up_settings.this.telemetry_checks_enabled
    telemetry_model      = data.sreagent_alert_follow_up_settings.this.telemetry_model_enabled
    informative_learning = data.sreagent_alert_follow_up_settings.this.informative_learning_enabled
  }
}
```

## Schema

### Read-Only

- `ages` (String) The minutes after which an open alert is first checked, nudged, carded and escalated, by severity.
- `configured` (Boolean) Always true: every organization has this resource. A platform that does not serve it fails the read with an error instead.
- `defaults` (Boolean) True when the values are the platform's defaults, not a choice of the organization.
- `demoted` (String) The kinds of alert that are only being suggested for now, each with the two alerts behind it.
- `enabled` (Boolean) Whether SRE Agent checks alerts that stay open. Off until an organization admin switches it on.
- `id` (String) The row's identifier on the platform.
- `informative_expire_hours` (Number) The age a newly approved informative kind closes its alerts after, in hours.
- `informative_kinds` (String) The informative kinds that are proposed or approved, as data.sreagent_alert_informative_kinds answers them.
- `informative_learning_enabled` (Boolean) Whether SRE Agent suggests which alerts are informative: once a day it reads the last 30 days of alerts and suggests the kinds that close by themselves with nobody acting. It only suggests; an organization admin approves or declines each. Off until an organization admin switches it on, and it needs enabled.
- `resolve_modes` (String) What the follow-up does with an alert its source says has cleared, by severity: auto resolves it, suggest only offers Resolve, off does nothing.
- `still_active_enabled` (Boolean) Whether SRE Agent also chases an alert that stays open with nobody on it: after the nudge, card and escalate ages it reminds the person on call, opens a card, and can page the person on call (or the next step of the escalation chain) for a critical or high alert its source still reports as firing. Off until an organization admin switches it on, and it needs enabled to do anything.
- `telemetry_checks_enabled` (Boolean) Whether SRE Agent judges alerts it cannot ask directly: Datadog monitors, New Relic issues, silence and the alert's own condition. Off until an organization admin switches it on; SRE Agent may close an alert whose condition it read wrongly, and Reopen undoes it. It needs enabled to do anything.
- `telemetry_model_enabled` (Boolean) Whether the organization's own AI provider works out a check for an alert that states none (a hint that only suggests). Off until an organization admin switches it on; it needs telemetry_checks_enabled.
- `updated_at` (String) When the setting last changed, or null while it holds the defaults.
- `week` (String) What the follow-up did in the last 7 days, with the nudges, cards and escalations.

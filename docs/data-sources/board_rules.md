# sreagent_board_rules (Data Source)

Every board_rule row, read-only. The board's rules: each runs actions on a card when something happens to it (a trigger such as a card being created or moved, or sitting in a column or past a due date), when its conditions hold. Read only: an organization admin writes a rule on Settings, Board rules or over MCP, and the platform publishes no Terraform type for it. A rule's `trigger`, `conditions` and `actions` are JSON; the condition kinds are service_is, has_label, lacks_label, team_is, priority_is, source_is, column_is and assignees, and the action kinds are assign, assign_on_call, set_priority, add_label, remove_label, move, comment, remind, add_checklist, add_checklist_template and assign_to_agent. Needs platform v0.525.0.

## Example Usage

```terraform
# Read only: an organization admin writes the board's rules in Settings, Board rules.
data "sreagent_board_rules" "all" {}

output "enabled_rules" {
  value = [for r in data.sreagent_board_rules.all.items : r.name if r.enabled]
}

output "first_rule_actions" {
  value = length(data.sreagent_board_rules.all.items) > 0 ? jsondecode(data.sreagent_board_rules.all.items[0].actions) : []
}
```

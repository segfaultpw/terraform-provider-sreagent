# sreagent_alert_informative_kinds (Data Source)

Every alert_informative_kind row, read-only. The informative kinds of alert (kinds marked expected): by default the proposals and the approved kinds, or the ones with one status, or all, newest first, at most 220. A person proposes a kind from an alert and an organization admin decides it in the app (or over MCP); Terraform only reads them.

## Example Usage

```terraform
# The kinds of alert marked expected. By default the proposals and the approved
# kinds; status = "all" also lists the declined and retired ones.
data "sreagent_alert_informative_kinds" "approved" {
  status = "approved"
}

output "approved_kinds" {
  value = [for k in data.sreagent_alert_informative_kinds.approved.items : k.label]
}
```
